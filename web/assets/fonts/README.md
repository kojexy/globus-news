# Bundled typefaces

PT Serif Regular, Bold and Italic, and Oswald variable are bundled locally for offline and consistent Android TV rendering.

Sources: https://github.com/google/fonts/tree/main/ofl/ptserif and https://github.com/google/fonts/tree/main/ofl/oswald

Original SIL Open Font License texts are included as PTSerif-OFL.txt and Oswald-OFL.txt. Typeface files are unmodified.
