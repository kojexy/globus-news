# Новости с Луны

Полноэкранная газета для компьютера и Android TV. Весь доступный текст открывается сразу в двух колонках. Без боковых панелей, постоянных кнопок и отдельного режима «читать».

**[Открыть приложение](https://kojexy.github.io/globus-news/)** · **[Скачать APK](https://github.com/kojexy/globus-news/releases/latest/download/globus-news.apk)** · [Облачные сборки](https://github.com/kojexy/globus-news/actions)

## Два основных действия

- **↓** — продолжить эту новость на следующей газетной полосе.
- **→** — следующая новость, всегда с начала.
- **↑** — предыдущая полоса этой новости.
- **←** — предыдущая новость.
- **OK / Меню** — открыть настройки; **Назад** — закрыть меню. Вне меню кнопка Назад на Android выходит из приложения.

На компьютере колесо мыши продолжает текст, клик по газете открывает меню. `S` — настройки, `C` — страны, `F` — полный экран. На сенсорном экране работают горизонтальные и вертикальные свайпы.

## Газетная полоса

Две колонки читаются слева направо, затем вниз к следующей полосе. Слова не пропадают и не повторяются на границах колонок. Короткие статьи по возможности распределяются между колонками по абзацам. Сверху — только страна, редакция, время и небольшая подпись. Картинка Незнайки остаётся значком приложения, но не занимает место внутри полосы.

12 сдержанных оформлений: «Утренняя», «Большая газета», «За кофе», «Архив», «Северная», «Типография», «Воскресная», «Телеграф», «Библиотечная», «Лунный выпуск», «Почтовая», «Вечерняя». При смене новости оформление меняется; при продолжении той же статьи остаётся прежним. Можно закрепить один стиль. Базовая текстура бумаги создана ImageGen, остальные различия — цвет, шрифт и тонкие типографские детали. Иллюстрации к самим новостям не выдумываются.

## Настройки и сохранение

В меню: размер текста 50–180% с шагом 5%, интервал 1.3 / 1.5 / 1.7, выравнивание, оформление бумаги, светлая / тёмная тема, автоперевод / оригинал, фильтр стран. Настройки сохраняются на устройстве. Идентификатор Android и подпись прежние, APK устанавливается поверх прошлой версии с сохранением данных.

Автоперевод на русский включён. Доступные статьи извлекаются с сайта редакции и переводятся заранее Argos Translate, без пользовательского API-ключа и платного сервиса. Если редакция отдаёт только аннотацию, она помечается в строке источника. Подписки не обходятся. Оригинал и сведения об источнике доступны через OK. Машинный перевод может содержать ошибки.

## Интернет и источники

Выпуски собираются автоматически каждые 3 часа, каждый день. Приложение проверяет обновления каждые 10 минут, при возвращении на экран и восстановлении сети. Новая загрузка не прерывает чтение: свежий выпуск применяется при следующей новости. Последний выпуск сохраняется; APK содержит резервную копию. GitHub может задерживать расписание, состояние и время выпуска видны в меню. После 6 часов без обновления появляется короткое предупреждение.

12 редакций, 8 стран: РБК, ТАСС, Интерфакс, Лента.ру, NPR, The New York Times, CGTN, BBC News, DW, France 24, The Japan Times, The Hindu. Флаг обозначает страну редакции. Внутри страны сначала идут материалы с доступным текстом, затем остальные свежие заметки. Статьи старше 72 часов не включаются в очередь. Очень длинные материалы ограничены 40 тысячами символов и помечаются как фрагмент.

## Установка и разработка

На компьютере откройте веб-адрес. На Android TV / Google TV установите APK через файловый менеджер. Требуются Android 6+ и актуальный Android System WebView. Для Samsung Tizen / LG webOS доступна веб-версия; эти платформы отдельно не проверялись.

Android Studio не нужна. GitHub Actions публикует сайт и собирает подписанный APK. Локально: `npm start`; проверки: `npm test` и `npm run test:feeds`; сборка: `npm run build`.

При переносе репозитория включите Pages → GitHub Actions, измените URL выпуска и настройте закрытые secrets `GLOBUS_KEYSTORE_BASE64`, `GLOBUS_KEYSTORE_PASSWORD`. Не меняйте подпись существующего приложения.

[Проверки](docs/VERIFICATION.md) · [Источники](docs/SOURCES.md) · [Оформление и ImageGen](docs/BRANDING.md)

Материалы принадлежат редакциям. Проект предназначен для личного чтения; коммерческая перепубликация требует проверки условий источников.


## Политика и фоновая классика — 1.3.0

По умолчанию лента показывает только политику: власть, выборы, дипломатию и международные отношения. OK → «Страны и фильтр» → «Все темы» возвращает общий выпуск. Страны и тематика сохраняются отдельно. Автоматический отбор учитывает рубрики RSS, адрес раздела, заголовок и аннотацию; возможны пропуски и неточности. При отсутствии подходящих материалов фильтр не подмешивает другие темы.

OK → «Настройки чтения и музыка» → «Фоновая классика». Музыка по умолчанию выключена; включение и громкость сохраняются. Начальная громкость 12%, диапазон 1–30%, на ползунке работают стрелки пульта. Непрерывный прямой эфир [Radio Swiss Classic](https://www.radioswissclassic.ch/en/reception/internet), без треклиста и перемотки, иногда с короткими объявлениями. Переключение новостей не прерывает музыку. При выходе/скрытии приложения поток останавливается, при возвращении подключается снова, только если функция включена. При обрывах сети — повторное подключение с увеличивающейся задержкой и резервный AAC-поток той же станции. Без интернета читается сохранённый выпуск, радио ждёт подключения. В обычном браузере после перезапуска может потребоваться первое нажатие из-за правил автоматического воспроизведения; Android TV запускает сохранённое включение автоматически.

## Расширенный мировой выпуск — 1.3.1

Сборщик объединяет общие, политические и международные RSS и выбирает до 30 материалов каждой редакции, с приоритетом политики. 13 редакций представляют Россию, Китай, США, Великобританию, Германию, Францию, Японию и Индию. В фильтре видно фактическое количество материалов каждой страны; при чтении страны чередуются. Количество зависит от свежих публикаций и доступности источников.

На каждом сборе добавляется до восьми новых полных статей каждой редакции; ранее собранные полные тексты сохраняются. Остальные записи показывают доступную RSS-аннотацию с явной пометкой. Это ограничивает длительность перевода растущего выпуска и не обрезает уже полученные статьи.

## Газетная типографика — 1.4.0

Встроенные кириллические PT Serif и Oswald обеспечивают одинаковую типографику на телевизоре и компьютере, в том числе без сети. Двенадцать оформлений разделены на ежедневные, литературные и архивные полосы. Основной кегль и управление сохранены.

Первый абзац выделен, остальные набраны с компактными интервалами и отступами. Растяжение межсловных пробелов ограничено; разделитель колонок заканчивается вместе с текстом. Длинные слова и продолжения абзацев переходят между страницами без добавленных дефисов и потери текста. Бумага светлее в зоне чтения и чуть темнее у краёв.

Служебные строки издателей (YouTube-плеер, «Поделиться», метки публикации) очищаются до перевода и при показе старых сохранённых выпусков. Содержательные упоминания этих сервисов и политические цитаты сохраняются.
