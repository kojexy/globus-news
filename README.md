# Новости с Луны

![Незнайка читает газету](web/assets/moon-icon-192.png)

Мировые новости на русском для компьютера и Android TV. Одна новость на экран; OK открывает текст статьи, стрелки перелистывают страницы. Размер текста регулируется под телевизор.

**[Открыть приложение](https://kojexy.github.io/globus-news/)** · **[Скачать APK](https://github.com/kojexy/globus-news/releases/latest/download/globus-news.apk)** · [Сборки и обновления](https://github.com/kojexy/globus-news/actions)

## Читать и управлять пультом

| Экран | ← → | OK | Назад |
|---|---|---|---|
| Лента | Предыдущая / следующая новость | Читать статью | Выйти из Android-приложения |
| Статья | Предыдущая / следующая страница | Открыть меню | Вернуться к ленте |
| Меню | Перемещение между кнопками | Выбрать | Закрыть |
| Ползунок размера | Уменьшить / увеличить на 5% | — | Закрыть настройки |

В ленте ↑ открывает меню. Кнопка «Меню» пульта также открывает меню приложения. В меню доступны страны, размер текста, перевод, оригинал и обновление. Все действия доступны стрелками и OK без мыши. На компьютере: `F` — полный экран, `S` — настройки, `C` — страны, `Esc` — назад.

## Полные статьи

Публично доступные статьи извлекаются с сайта редакции и переводятся заранее. В карточке есть отметка «Есть текст статьи». При чтении текст разбивается на страницы с сохранением абзацев; реклама и элементы навигации исключаются. Новая загрузка не закрывает текущую статью и не сбрасывает страницу.

Не каждая редакция отдаёт полный текст: возможны подписка, технический запрет или только RSS-аннотация. Тогда приложение явно сообщает об ограничении и предлагает оригинал. Платный доступ не обходится, недостающий текст не сочиняется. Очень длинные материалы ограничены 40 тысячами символов и помечаются как фрагмент.

## Настройки

- Масштаб текста: **50–180%**, шаг 5%; быстрые варианты «Плотнее», «Обычный», «Крупный». Стандартный текст уменьшен относительно версии 1.0.
- Межстрочный интервал: 1.3 / 1.5 / 1.7.
- Ширина полного текста: весь экран или колонка.
- Автоперевод на русский включён по умолчанию; можно читать оригинал.
- Бумажная и тёмная темы.
- Страны: Россия, США, Китай, Великобритания, Германия, Франция, Япония, Индия; произвольный набор или «Только Россия».

Настройки и фильтр сохраняются на устройстве. Обновление с версии «Глобус» сохраняет их; идентификатор Android и ключ подписи прежние.

## Интернет и свежие новости

GitHub Actions собирает и переводит новые выпуски **каждые 3 часа, каждый день**. Приложение проверяет выпуск каждые 10 минут, после возвращения на экран и после восстановления сети. Есть ручная кнопка обновления. Время выпуска видно в шапке; после 6 часов без свежего выпуска появляется предупреждение. GitHub может задерживать расписание.

Последний выпуск сохраняется в браузере; APK содержит резервный выпуск. Новость, открытая для чтения, остаётся на экране при фоновом обновлении. Статьи старше 72 часов не включаются в очередь.

## Источники и перевод

12 прямых RSS-лент, 8 стран: РБК, ТАСС, Интерфакс, Лента.ру, NPR, The New York Times, CGTN, BBC News, DW, France 24, The Japan Times, The Hindu. Флаг — страна редакции, а не место события. Внутри страны статьи с доступным текстом идут первыми, затем — остальные свежие заметки. Это подборка известных редакций, не рейтинг.

Артикульный текст извлекает Trafilatura. Английские тексты автоматически переводит [Argos Translate](https://github.com/argosopentech/argos-translate), модель en → ru, на GitHub runner. Платных API и пользовательских ключей нет. Можно читать оригинал. Машинный перевод может содержать ошибки; приложение не проверяет сообщения редакций независимо.

## Установка

На компьютере достаточно открыть веб-адрес — устанавливать ничего не нужно. На Android TV / Google TV откройте APK в файловом менеджере и разрешите установку этому менеджеру. Требуются Android 6+ и актуальный Android System WebView. Для Samsung Tizen и LG webOS предназначена веб-версия; эти платформы отдельно не проверялись.

## Разработка

Android Studio не требуется. Изменения в GitHub запускают публикацию сайта и облачную сборку подписанного APK. Локальная веб-версия: `npm start`. Проверки: `npm test` и `npm run test:feeds`. Сборка статики: `npm run build`.

При переносе на другой репозиторий: включите Pages → GitHub Actions, поменяйте URL выпуска в Android workflow и задайте свои закрытые signing secrets `GLOBUS_KEYSTORE_BASE64` и `GLOBUS_KEYSTORE_PASSWORD`. Секреты в исходники не попадают. Смена подписи не позволит установить APK поверх прежней версии.
