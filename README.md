# Глобус

Новости мира на русском для компьютера и Android TV. Одна новость на экран, без автопрокрутки. Новости переключаются стрелками или пультом. Выбранные страны и размер текста сохраняются на устройстве.

**[Открыть приложение](https://kojexy.github.io/globus-news/)** · **[Скачать Android TV APK](https://github.com/kojexy/globus-news/releases/latest/download/globus-news.apk)** · [Облачные сборки](https://github.com/kojexy/globus-news/actions)

## Как пользоваться

- На компьютере: откройте приложение в браузере; `F` включает полный экран.
- На Android TV / Google TV: установите `globus-news.apk` из Releases, разрешив установку этому загрузчику. Приложение появится на главном экране телевизора.
- На Samsung Tizen, LG webOS и обычном компьютере: используйте веб-версию в современном браузере. APK подходит только для Android, работу браузера конкретного телевизора нужно проверять отдельно.
- `← →` — предыдущая / следующая новость. После последней новости лента возвращается к первой.
- `↑ ↓` — страницы длинной заметки. Текст не обрезается по высоте.
- `OK / Enter` — выбор стран; `Назад / Esc` закрывает окно. `Меню` на Android TV или `S` на клавиатуре — настройки чтения.
- Есть режим «Только Россия», произвольный набор стран, три размера текста и два оформления.
- Свайп вправо на сенсорном экране переключает на следующую новость.

## Источники и перевод

8 стран, 10 прямых RSS-лент: РБК, ТАСС, NPR, The New York Times, CGTN, BBC News, DW, France 24, The Japan Times, The Hindu. Это подборка известных редакций, а не рейтинг популярности. Флаг обозначает страну редакции, а не страну события. Китай представлен англоязычной редакцией CGTN; её государственный статус указан в интерфейсе.

Приложение показывает **заголовок и краткий текст редакции**, со ссылкой на оригинал. Основной источник — RSS. Если в RSS нет аннотации, используется публичное описание страницы (`og:description`), с указанием происхождения в карточке источника. Полные статьи, фотографии и платные материалы не извлекаются; подписки не обходятся. Факты не дописываются генератором. Если редакция передала только заголовок, это явно указано. Текст ограничен 650 символами; длинные фрагменты заканчиваются многоточием.

Англоязычные ленты автоматически переводит [Argos Translate](https://github.com/argosopentech/argos-translate), модель `en → ru`, на сервере GitHub Actions. Ключи и платный сервис не нужны. Перевод машинный, его точность не гарантируется. При сбое перевода показывается помеченный оригинал, при сбое источника — его недавние новости из кеша. Приложение не является независимой проверкой сообщений редакций.

## Обновление и автономная работа

- GitHub Actions собирает выпуск каждые 3 часа; расписание GitHub может задерживаться. Клиент проверяет выпуск каждые 10 минут и при возвращении в окно.
- Время выпуска и недоступные источники видны в приложении. После 6 часов появляется предупреждение о старом выпуске.
- Новости старше 72 часов не попадают в очередь. Если выбранная страна пуста, показывается явное пустое состояние.
- Последний выпуск сохраняется в браузере. Android-приложение содержит резервную копию выпуска на момент сборки.
- Новый фоновый выпуск не прерывает текущую заметку: он применяется при следующем переключении.
- Фильтры хранятся локально, без аккаунта и синхронизации. Очистка данных браузера / приложения сбрасывает их.

## Разработка без Android Studio

Достаточно редактировать файлы на GitHub. Workflow `Refresh news and publish website` обновляет сайт, `Build Android TV APK` собирает и подписывает APK в Releases. Android Studio, SDK и модель перевода на пользовательском компьютере не нужны.

На новом форке нужно включить Pages → GitHub Actions, изменить URL репозитория в workflow и настроить свои signing secrets `GLOBUS_KEYSTORE_BASE64`, `GLOBUS_KEYSTORE_PASSWORD`. Не меняйте ключ подписи при обновлениях: Android не установит обновление поверх приложения с другой подписью. Секреты находятся только в GitHub Actions Secrets, в исходниках их нет.

Локальный запуск веб-версии: `npm start`. Проверки: `npm test` и `npm run test:feeds`. Сборка статики: `npm run build`. Публичные JSON-данные не содержат пользовательских настроек.

## Границы

Крупный текст помогает читать с расстояния; это не медицинская защита зрения. Источники могут быть недоступны в отдельных странах, а оригиналы могут требовать подписку. Бесплатное расписание зависит от доступности и правил GitHub Actions; для публичных репозиториев GitHub может отключить расписание после 60 дней без активности. Следите за [Actions](https://github.com/kojexy/globus-news/actions). RSS-материалы принадлежат редакциям: приложение предназначено для личного чтения, коммерческая перепубликация требует проверки условий источников.
